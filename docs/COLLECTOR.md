# 采集系统说明

平台：全国建筑市场监管公共服务平台 `https://jzsc.mohurd.gov.cn/data/company`
红线（沿用至今，不改）：只用页面公开筛选与详情；不绕过验证码，出现验证即停、等人处理；可见浏览器；自动操作间隔 0.5～0.8 秒。

## 为什么要遍历细化

平台对单个检索组合最多展示 30 页 × 15 条 = **450 条**。只查「资质 × 山东（省级）」时，热门资质会超过 450 而被静默截断。所以遍历按组合切分：

1. **市级组合**：资质 × 山东 16 地市（济南、青岛、淄博、枣庄、东营、烟台、潍坊、济宁、泰安、威海、日照、临沂、德州、聊城、滨州、菏泽）。
2. **OVERFLOW 下钻**：组合跑满 30 页 → state 标记 `"status": "OVERFLOW"`，不算完成；自动改为该市的区县逐个跑。
3. **区县仍 OVERFLOW**：打印 `[overflow-county]` 留人工决定，不静默截断、不冒充采全。

历史单组合「建筑工程施工总承包一级 × 山东」曾采到 356 条 < 450（那份是测试数据，已于 2026-11-22 删除）；默认组合的输出文件名保留 `collector/data/mohurd_shandong_level1.json`，采集时自动生成。

## 枚举数据（必须来自平台本身）

- `collector/qualifications.json` — 资质对话框里的全部资质名称，逐字抄录（含类别信息时另记）。文件不存在时代码只知道已验证的那一个资质。
- `collector/shandong_counties.json` — `{"地市": ["区县", ...]}`，以平台属地选择器实际选项为准。文件不存在时，OVERFLOW 的市会报 `[needs-county-data]`。

> 探路结果（资质清单全文 / 平台是否提供市级、区县级选择器）：见本文件末尾「探路记录」，以最近一次浏览器探路为准。若平台根本没有市/区县筛选，下钻方案需改为其他可切分条件，届时更新本节。

## 文件与状态

- 每个组合：`collector/data/<组合文件>.json` + 同名 `.state.json`（含 `records / complete / last_company / source_query / pages_seen / overflow / status`）。
- 每条企业记录带 `source_query {qualification, province, city, county}`，入库不依赖它，但审计覆盖面靠它。
- 断点续跑：state 与本组合已完成企业集合决定跳过哪些；**搬文件时 JSON 与 state 必须成对**。

## 访问不到平台时

先把 DNS 改成 `114.114.114.114` 再试（Hu 2026-11-22 提示，该平台在默认 DNS 下可能解析不到/打不开）。

## 验证码与通知

验证码（极验/滑块）出现时脚本停住并通过 Bark 提醒一次（根目录 `bark.url` 或环境变量 `BARK_URL`），人在可见浏览器里完成后自动继续。脚本从不点击验证码。
